# Contributing

## Branches
- `main` — stabilne buildy, nie pushujemy bezpośrednio
- `dev` — główna gałąź rozwoju
- `osoba/nazwa-zadania` — każda osoba prowadzi swojego brancha i pracuje na nim na codzień

## Pull Requesty
- Każdy PR powinien być zatwierdzony przez minimum 1 osobę
- PR zawsze idzie do `dev`, nigdy do `main`
- Opisz krótko co zrobiłeś

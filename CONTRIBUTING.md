# Contributing

## Branches
- `main` — stabilne buildy, nie pushujemy bezpośrednio
- `dev` — główna gałąź rozwoju
- `feature/nazwa-zadania` — tutaj pracujemy na co dzień

- ## Nazewnictwo branchy
-feature/drone-physics
-feature/player1-controls
-fix/obstacle-collision

## Pull Requesty
- Każdy PR powinien być zatwierdzony przez minimum 1 osobę
- PR zawsze idzie do `dev`, nigdy do `main`
- Opisz krótko co zrobiłeś i jak to przetestować
- Usuń branch po mergu
